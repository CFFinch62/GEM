# Ruby Beginner Tutorial Series

Welcome to the comprehensive Ruby programming tutorial series! This collection of 10 lessons will take you from complete beginner to having a solid foundation in Ruby programming.

## 📚 Tutorial Overview

This tutorial series is designed to teach programming fundamentals using the Ruby language. Each lesson builds upon the previous ones, introducing new concepts progressively.

### 🎯 Learning Objectives

By the end of this tutorial series, you will be able to:
- Write basic Ruby programs
- Understand variables, data types, and operators
- Use conditional statements and loops
- Work with arrays and hashes
- Create and use methods (functions)
- Understand object-oriented programming with classes and objects
- Build interactive console applications

## 🚀 How to Use This Tutorial

### Prerequisites
- Ruby installed on your computer
- A text editor or IDE (RIDE recommended!)
- Basic computer literacy

### Getting Started
1. Start with lesson 1 and work through them in order
2. Read the comments in each file carefully
3. Run each program to see the output
4. Experiment with the code - change values and see what happens
5. Complete the exercises at the end of each lesson

### Running the Programs
To run a Ruby program:
```bash
ruby 01_hello_world.rb
```

Or use the RIDE IDE:
1. Open the file in RIDE
2. Click "Run Code" or press F5
3. View the output in the Console tab

### Learning Tips
- **Practice regularly:** Try to code a little bit every day
- **Experiment:** Don't just read the code - modify it and see what happens
- **Take notes:** Write down important concepts
- **Build projects:** After completing the tutorials, try building your own programs
- **Ask questions:** If something doesn't make sense, research it or ask for help

## 🔧 Troubleshooting

### Common Issues
1. **Syntax Errors:** Check for missing `end` statements, unmatched quotes, or typos
2. **Logic Errors:** Use `puts` statements to debug and see what your variables contain
3. **Input Issues:** Remember to use `.chomp` when getting user input
4. **Type Errors:** Make sure to convert strings to numbers when needed (`.to_i`, `.to_f`)

### Getting Help
- Read error messages carefully - they often tell you exactly what's wrong
- Use the Ruby documentation: https://ruby-doc.org/
- Practice debugging by adding `puts` statements to see what your code is doing
- Break complex problems into smaller parts
